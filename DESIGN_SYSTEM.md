# Beauty by Mica design system

Creative direction by the distinct Astra design agent, 21 October 2026: “private beauty atelier, photographed like a magazine.” This is an interim direction for client review, not client approval.

## Tokens
- Pink #F5B8C1, ink #101010, paper #FFFFFF. Pale pink surfaces derive from the primary. Secondary text #606060; borders use ink at 15%.
- Instrument Serif regular and real italic: expressive editorial headings. Manrope variable: readable body, controls and small structured labels. Fonts are locally hosted with SIL license files.
- Hero 62–126px responsive; section titles 43–80px; body 13–15px; compact captions 8–10px. Small captions are secondary only; all functional controls have readable labels.
- Mobile gutter 22px; desktop fluid gutter up to 80px; content width 1600px. Sections 76px mobile / 110px desktop. Hairline dividers, mostly square corners, no card-heavy dashboard treatment.

## Composition
White split hero, black serif headline with one pink brush underline, custom cosmetic still life. Mobile leads with the text and booking action, then imagery. A small AI concept caption remains visible.
The artist introduction uses asymmetrical whitespace. Three abstract cosmetic studies suggest mood directions without promising unconfirmed services. Black comparison section interrupts the rhythm. The portfolio moodboard uses asymmetric image sizes. Exact pink fills the final booking block; footer is black.

## Components and behavior
- BM typographic mark with heart detail is provisional, not a redrawing of the original portrait logo.
- Dark rectangular buttons, 44–54px minimum control height. Inline SVG arrows and four-point stars.
- Native language select with flags and explicit names; a fully translated static document per locale, preserving current fragment.
- Mobile menu is a disclosure with aria-expanded, Escape handling and hidden inactive content. Fixed mobile booking bar respects safe-area inset; footer clearance prevents overlap.
- Booking preview uses native dialog focus containment, Escape and focus restoration. No fabricated booking success.
- Comparison uses native range input for mouse/touch/keyboard; two abstract CSS studies and persistent demo labels.
- 900ms underline reveal only, subtle hover movement. Reduced motion disables all animation and smooth scrolling. No blocking intro.

## Asset provenance
`public/images/hero.webp` and `detail.webp` are locally optimized versions of one image generated with the built-in imagegen tool. They are an editorial placeholder; no people, products for sale or actual client results are represented.
Prompt: luxury editorial cosmetics still life on #F5B8C1 with one black powder brush, pink compact, loose powder and black lipstick; raking daylight, tactile shadows, generous negative space; no people, faces, text, logos, gold, beige or watermark. A derivative square crop is used for the detail panel.

## Future identity
Replace the provisional BM mark with the approved navigation variant, add the original circular logo in a suitable brand area, and use client-approved portfolio photographs. Retain aspect ratios and contrast when swapping assets. The original logo is required for final identity approval.
